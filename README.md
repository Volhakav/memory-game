# Memory Game

Игра на поиск пар: игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов.

## Особенности проекта
- Вся разметка интерфейса генерируется динамически с помощью JavaScript (`document.createElement`).
- Чистый HTML, CSS и JavaScript без использования сторонних фреймворков и библиотек.
- Плавная 3D-анимация переворота карточек.
- Адаптивный дизайн, корректно отображающийся на экранах от 320px.
- Сохранение топ-10 лучших результатов в `localStorage` с сортировкой по числу ходов и дате.
- Универсальные модальные окна (победа и таблица лидеров) с закрытием по клику на оверлей, кнопку или клавишу `Escape`.
